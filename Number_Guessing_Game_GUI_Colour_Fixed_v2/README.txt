NUMBER GUESSING GAME - GUI MINI PROJECT (COLOUR FIX V2)

This version uses custom clickable labels for buttons because some macOS Tkinter button styles may ignore their background colour.

HOW TO RUN
1. Extract this ZIP into a NEW folder.
2. Open the new Number_Guessing_Game_GUI_Colour_Fixed_v2 folder in VS Code.
3. Run main.py using:
   python main.py
   or on some systems:
   python3 main.py

Important: Do not run the old main.py from your previous extracted folder. Run the main.py included in this ZIP.

Buttons use high-contrast white text on purple/green/dark blue backgrounds.
